A shelving system that reconfigures between three distinct states: upright bookcase, horizontal desk surface with integrated storage, and open shelving wall. The same set of panels, the same connectors, three completely different pieces of furniture. The project ran from system design through component engineering and into physical prototyping.

<h2>The system</h2>

Regal 3.0 is built from a standardised panel grid. Each panel carries the same slot and tab geometry on all four edges, so any panel can connect to any other in any orientation. The module dimensions were derived from an ergonomic analysis of reach zones: the tallest configuration puts its top shelf at the upper limit of comfortable standing reach; the lowest puts its working surface at seated desk height.

<h2>The locking component</h2>

Posizione B introduces a structural problem the slot-and-tab system alone cannot solve: when the main body tilts to become a desk surface, it needs a rigid bracket to hold the angle under load. The D1 component was designed specifically for this.

<h2>From design to prototype</h2>

The D1 was taken through to a physical prototype via FDM 3D printing. Before printing, the component was analysed in slicer software to verify wall thickness, infill density, support requirements, and print orientation. The cross-section visualisation confirmed the curved arms would print cleanly without supports if oriented vertically.

<h2>The process</h2>

The project ran across three deliverable steps: the functional component abaco and panel layout, the full technical drawing of the D1 locking bracket, and the slicer analysis and physical print. Each step fed directly into the next; the dimensions on the abaco set the slot tolerances the D1 technical drawing had to match, and the technical drawing set the geometry the slicer had to validate.
